What this is

A browser twin of the firmware in firmware/. Both draw into a 1-bit 128×64 framebuffer — the same memory an SSD1306 OLED exposes — so what you tune here is what the device shows. The point is to settle the face design and the reaction timings before buying parts.

Firmware

firmware/keychain_buddy/keychain_buddy.ino — Arduino/ESP32. Same state machine as this page: idle → blink → happy | dizzy | sleep, driven by a tap on the screen button and by an MPU6050 (or the ESP32's own accelerometer on S3 variants). Libraries: Adafruit_SSD1306, Adafruit_GFX.

No hardware yet — this page is the simulator, and the sketch compiles against the same constants. Flash it when the parts arrive.
